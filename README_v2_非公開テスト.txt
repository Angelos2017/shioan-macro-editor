しお✦あんマクロエディタ v2.0 非公開テスト版
================================================

【このバージョンについて】
「マクロを知らなくても、やりたいことから作れる」を優先した、操作性検証用の試作版です。
旧v1.2.1の辞書・クラフト・かんたん作成・取り込み・動作プレビュー等を残し、新しい「おまかせ作成」を先頭に追加しました。

【おまかせ作成の内容】
・挨拶：発言先、セリフ、任意の待機時間を選ぶだけ
・セリフを順番に流す：複数の文章と間隔（<wait.N>）を設定
・エモート：動作のみ／オリジナル文章のみ／両方
・文章エモート：ターゲット名 <t> を自動挿入可能
・エモート検索：「笑う」「笑い」等の簡単な表記ゆれ補助（おまかせ作成内）
・クラフト：既存のクラフト作成画面へ案内
・完成マクロ：コピー、従来の取り込み編集、動作プレビューへ送る
・行数確認：15行超過はコピー等を停止

【例】
あいさつ：/p よろしくお願いします！ <wait.2>
文章エモート：/em は<t>に苦笑いをした
（FF14では /em は自分の名前に続く文章を指定する想定です。ターゲットなしだと <t> の置換は成立しません）

【非公開テストの注意】
1. 「非公開テスト版」というタイトル表示自体はアクセス制限になりません。
2. GitHub Pagesにアップロードすると、サイトが公開される可能性があります。
3. 利用条件・辞書データの権利関係を確認中のため、公開再開はしないでください。
4. オフラインで試す場合は、ZIPを展開してフォルダごと保管し、index.htmlをブラウザで開いてください。
   ブラウザによってはfile://上でクリップボードや保存等の動作が制限されます。
5. このZIPは既存の辞書データを含む試験用の開発一式です。再配布せず検証用にとどめてください。
6. FF14の動作を自動化せず、実行・文法の保証もしません。

【ユーザーレビューで残る課題】
・初心者向け導線の検証と、用途ごとの質問形式の拡充
・総合辞書のソート、検索関連語の充実
・GitHubへの直接報告リンクの見直し
・辞書データの出典・利用条件の確認
