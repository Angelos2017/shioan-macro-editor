しお✦あんマクロエディタ v1.2.1 プレビュー版

■ GitHubへの更新方法
ZIPを解凍し、内容の全ファイルをGitHubリポジトリのルート（一番上の階層）へアップロードしてください。
GitHub → Add file → Upload files → Commit changes で同名ファイルを上書きできます。
フォルダごとアップロードしないようにご注意ください。
旧版の README_v1.1_プレビュー版.txt は残っていてもアプリ動作には影響しません。

■ 今回の追加
・「▶ 動作プレビュー」タブを新設（取り込み欄のマクロを対象）
・チャット、クラフトアクション、エモートほかのコマンドを順番に表示
・/wait 2、<wait.3> 形式の時間指定を読み取り
・再生／一時停止／最初から／再チェック
・1倍、2倍、4倍、8倍速での再生（時刻表示はゲーム内想定秒数のまま）
・15行制限、コマンド名の辞書照合、引用符、待機指定の形式などを簡易点検
・エラー／注意／参考を分けて表示
・チャットの2秒／3秒比較や、アクション待機の参考表示

■ 重要な制限
あくまでもマクロの簡易シミュレーションです。FF14本体と連動せず、
アクション・エモートの発動成功、CP、リキャスト、ゲーム側の遅延、
チャット制限、ログの実際の表示を保証しません。
辞書にないコマンドは誤りと断定せず、参考情報として示します。
書式チェックは全コマンドの引数検証を保証しません。
「待機合計」は明示した待機時間のみの合計です。
実際のアクション所要時間や実行条件は含みません。

■ 引き継ぐ機能
セージグリーンとラベンダーのテーマ、ライトモード標準、
エモート辞書294候補、総合コマンド辞書540定義、代名詞35項目、
クラフト作成、マクロの自動保存、確認付きクリアなどv1.1の機能を引き継ぎます。

■ まず試してほしい例
/say みなさん こんばんは！
/wait 2
/say はじめましょう！
/ac "確信" <wait.3>
/echo 完了！

上記を「取り込み」に貼り付けて「動作プレビュー」を選び、再生速度を変えてみてください。
ゲーム内の実行ではなく、画面で待機時間と順番の確認ができます。

【v1.2.1 追加更新】
「かんたん作成」→「チャットで発言」の待機時間をプルダウンから数値入力へ変更。
空欄は待機なし。1〜60の整数を入力すると、セリフの末尾に <wait.数字> を自動付与します。
チャットの最後の行にも待機指定が付くよう修正。編集ボタンから待機秒数の変更も可能。
なお、ゲーム内のチャット制限や表示間隔は各自で実機確認してください。
