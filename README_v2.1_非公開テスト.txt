しお✦あんマクロエディタ v2.1 非公開テスト版
======================================
【使い方】
このZIPを解凍し index.html をブラウザで開いてください。
一部のブラウザではローカルファイルの制限により辞書の読み込みが制限されることがあります。
その場合、ローカルHTTPサーバーなどの利用が必要です。
GitHub Pagesへアップロードした場合は一般公開となる可能性があります。
利用条件の確認が終わるまでは公開しないでください。

【v2.1 の変更】
・「おまかせ作成」「かんたん作成」を「マクロ作成」に統合
・「おまかせ作成」「自由に作成」の切り替え。作成内容を自由編集へ引き継げます
・保存済みの自由編集内容を置き換える際は確認します
・シャウト／エール時のみ待機時間の注意表示（2秒以上は目安です）
・カラーテーマ5種類（しお✦あん／森のティータイム／ラベンダーガーデン／陽だまり／月夜の庭）
・テーマ設定はブラウザに保存されます
・メニュー「エモート辞書」へ変更
・初心者向けガイドの文字色を調整
・GitHubへの報告リンク／報告文コピーのUIを除去
・辞書の別名／照合状況などは総合辞書内の詳細表示に残します
・「セリフを順番に流す」のサブ文を「接客やイベントの進行に」へ修正

【留意事項】
・クラフト作成、辞書検索、マクロ動作プレビューなど既存機能は継承しています。
・ブラウザでの実操作テストは実行環境で制限されたため未完了です。
・辞書データの使用条件は確認中です。公開再開の許可を意味するものではありません。
・マクロのゲーム内動作を保証するものではありません。
